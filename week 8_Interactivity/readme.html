Interactivity Exploration

For this exploration, I wanted to create a dynamic, interactive sketch that responds to both mouse and keyboard inputs while utilizing array methods we learned in class. When the user clicks the mouse (mousePressed), new values for position, speed, size, and random color are added to the arrays. Pressing any key (keyPressed) removes the oldest shape from the arrays. Also, shapes falling past the bottom of the canvas are automatically removed from the arrays or canvas.
